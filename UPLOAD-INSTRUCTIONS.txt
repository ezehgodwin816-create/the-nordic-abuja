THE NORDIC ABUJA — ADMIN UPGRADE

1. Replace the repository root admin.html with admin.html from this package.
2. In Supabase SQL Editor, run admin-setup.sql.
3. Do not change or upload anything inside images/.
4. Open the live admin page.
5. Sign out and sign back in with the existing admin account.
6. Test each sidebar module one at a time.

The admin uses only the publishable Supabase key. The secret key is not included.
The modules read actual database rows. Unknown columns are displayed dynamically rather than invented.
No fake hotel data is inserted by these files.
