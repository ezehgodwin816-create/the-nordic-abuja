# The Nordic Abuja — Premium Website Concept V1

This is a from-scratch, static front-end concept intended to be deployed on GitHub Pages.

## Important
This is a **concept redesign**, not an official The Nordic Abuja website. Do not publish it as an official site or use unverified operational claims without permission.

Several image files are placeholders. Replace them with licensed/approved hotel photography before presenting a production-ready version.

## Structure
- `index.html` — main homepage
- `rooms.html` — room collection
- `room-deluxe.html` — featured room detail
- `dining.html` — TARO Bistro & Bar
- `experience.html` — wellbeing/rooftop/concierge
- `events.html` — meetings & events
- `abuja.html` — city guide
- `gallery.html` — gallery
- `offers.html` — offers
- `contact.html` — contact and enquiry concept
- `assets/css/style.css` — global styling
- `assets/css/pages.css` — inner page styling
- `assets/js/main.js` — navigation, booking-demo UI, gallery lightbox, concierge, scroll effects

## Image setup
Put approved images in:
`assets/images/`

The HTML currently expects:
`hero.jpg`
`story.jpg`
`deluxe.jpg`
`taro.jpg`
`gym.jpg`
`rooftop.jpg`
`lounge.jpg`
`events.jpg`
`abuja.jpg`
`room.jpg`
`about.jpg`

If an image is missing, the browser will show a broken image until it is replaced.
